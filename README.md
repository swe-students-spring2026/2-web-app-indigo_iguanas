# Web Application Exercise

A little exercise to build a web application following an agile development process. See the [instructions](instructions.md) for more detail.

## Product vision statement

A simple mobile first habit tracker that helps users build small daily habits and visualize streaks.


## User stories
[User Stories](https://github.com/orgs/swe-students-spring2026/projects/73)<br>
Link To Task Board: https://github.com/orgs/swe-students-spring2026/projects/73 <br>

1. As a user, I want to sign up so that I can create a personal account and track my habits over time.
2. As a user, I want to log in securely so that my habits and progress are saved and private.
3. As a user, I want to create a new habit with a name and daily goal so that I can start building consistency in a specific area of my life.
4. As a user, I want to edit my existing habits so that I can adjust goals as my routine changes.
5. As a user, I want to delete a habit so that I can remove habits I no longer want to track.
6. As a user, I want to mark a habit as completed for the day so that I can maintain and grow my streak.
7. As a user, I want to see my current streak and time for next streak so I can stay motivated.
8. As a user, I want to search for a specific habit so that I can quickly find it without scrolling through my entire list.
9. As a user, I want to view my habits on a dashboard so that I can easily see what I need to complete today.
10. As a user, I want to view my profile with my completed habits and streak statistics so that I can track my long term progress 


## Steps necessary to run the software

### 1. Clone the Repository
```
Open The Terminal:
git clone https://github.com/swe-students-spring2026/2-web-app-indigo_iguanas.git
cd 2-web-app-indigo_iguanas
```

### 2. Install Python (Skip if installed)
```
Make sure Python 3.10 or higher is installed.
Verify by running:
python3 --version
```

### 3. Installing the Dependencies
```
Run in your terminal: python3 -m pip install --user -r requirements.txt
```

### 4. Configure the Environment 
```
Option A:
cp .env.example .env
nano .env
use the credentials we provided you, replace the example lines and paste the configuration
we provided you, then you save and exit.

Option B:
Manually add the .env and paste the configuration we gave you
```

### 5. Run the App
```
python3 app.py
```
